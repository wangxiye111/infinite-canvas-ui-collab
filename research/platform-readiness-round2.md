## 2. 可灵：Craft Anything 捕获的公开规则

来源：[可灵官方接入指南](https://klingai.com/app/mcp/guide)。Craft Anything 以 Clean room 模式捕获页面可见文字及截图，证据 `ev_3ee0df1af9b7e20b24f2526aab8a7d5d5c78153b6464e10b9d5f78545c601ed5`，记录为 `fnd_1`、`fnd_2`。

- 国内 CLI 包为 `@klingai/cli-cn`，通过 `kling login` 发起官方授权；MCP 地址为 `https://klingai.com/mcp`。网页登录不能替代每台电脑的工具授权。
- CLI／MCP 使用个人空间的付费灵感值，不支持赠送灵感值与团队权益；不能据此推断 REST API 也使用相同余额。
- 提交后的生成任务不能取消；结果链接有效期为 24 小时。停止本机等待不得显示为远端已取消；应用应及时保存原始文件。
- 链接过期后，先尝试查询原任务是否能取得可用链接；平台无法提供时说明原因，不自动重新生成。能否刷新下载链接尚未实测。

这些是平台文档约束，不是新增本项目的超时、并发或重试默认值。

### RunningHub

从已登录的[API 控制台](https://www.runninghub.cn/call-api/bill-task?tab=detail)进入“消费级-会员”，页面显示：

- 已有一项掩码显示的 API 密钥；本轮未点击复制、重置，也未创建新密钥。
- 该类型可调用 AI 应用和工作流；Model API／LLM 仅支持“企业级-共享”密钥。
- 使用会员 Key 调用会消耗付费积分，网站任务与 API 任务共用并发限制。
- 任务账单将积分、RH 币和钱包费用分列，不能用其中一项余额判断其他权益。

这与[官方 API 权益说明](https://www.runninghub.cn/runninghub-api-doc-cn/)一致。当前用户 Key 的实际可调用工作流、有效性、上传和下载仍需后续验证；已有网站成功记录不能替代从本项目提交的验收。不从用户历史记录擅自选定首批工作流。

## 4. LibTV 定向交互观察

重新打开用户指定的画布后，观察到：

- 左侧可添加节点、打开素材库及生成历史；画布另有资产管理、整理画布、小地图、连线显示和网格吸附入口。
- 添加菜单将节点类型与添加资源分开；资源可上传，也可从生成历史选择。
- 生成历史打开资产库面板：左侧为“生成历史／我保存的／我上传的”，主区有“本项目／全部项目”，可按全部、图片、视频、音频过滤。
- 当前项目为空，历史显示“暂无历史记录”。本轮没有新建节点或提交生成，未验证实际候选切换、历史拖入、节点删除后的任务归属、断网恢复或批量性能。

对本项目的设计建议：节点内部处理当前候选和批次；资产面板负责跨节点查找、筛选和复用，两者引用同一份本地素材。不要为了学习 LibTV 而加入首期之外的音频、导演台或脚本需求。此为设计建议，不声称 LibTV 内部采用同样的数据结构。
