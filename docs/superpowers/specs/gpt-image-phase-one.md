# GPT 生图第一阶段需求与验收

## 用户目标

在现有无限画布项目增量修改，不新建项目。暂时移出当前提示词库功能入口，保留代码与数据，以后由用户沉淀自己的提示词。画布图片节点与生图工作台共用本机 Codex 的 GPT 图片生成能力。新用户可通过明确引导完成检测与配置，但官方登录、账号授权与额度仍由用户完成和确认。

## 实现选择

沿用已有本地连接服务、生成渠道、任务持久化和结果导入链路；不另建平行后端。改用本机 Codex 原生图片工具，不将网页会员当成 API 额度，不读取或复制 Codex 认证文件，不使用第三方 helper 直接请求私有认证接口，不关闭正常权限检查。图片默认别名从官方目录选择有效默认驱动和 reasoning，仅覆盖本次图片进程；不继承用户全局模型、不改写全局配置。显式图片驱动无效时不自动替换，不重投不确定任务或回退付费 API。

前端通过可恢复功能开关暂停提示词库。明确点击配置后，添加或复用 Codex 图片渠道并选择为图片默认模型；现有渠道、凭据、文本/视频/音频默认值及单节点显式选择保持。运行状态区分本地服务、客户端安装、官方登录、原生图片能力、官方目录驱动及未知额度。

可灵、即梦、RunningHub 等保留已有适配与真实状态，ComfyUI 官方作为后续独立适配，不伪装成现已接通。平台名、认证、动作、任务与结果继续通过现有 provider 合约扩展。

## 安全与范围

- 工作区完整快照保留在项目旁的 canvas-local-snapshots；已逐文件与归档校验。不要清理、覆盖或提交既有未提交工作。
- 不改变共享权限，不推送、不发版，不修改用户全局 Codex 配置或账号。
- 检测读取本地帮助、版本、特性、登录状态与官方模型元数据。不创建推理线程或发送生成请求。
- 生成只由用户明确点击触发。无法继续的授权请求给出明确原因；不自动替用户批准。
- 不增加未经确认的超时、重试、尺寸或并发上限。结果按真实图片文件校验，不以文字回答假装出图。

## 验收清单

- [ ] 首页、导航、工作台、画布和配置不再出现当前提示词库入口；原有数据不删。
- [ ] 配置按钮重复点击不重复创建渠道，不覆盖其他配置，不自动生成。
- [ ] 未启动服务、CLI缺失、未登录、图片能力或官方驱动不可用分别能解释下一步；界面显示选中的目录驱动与 reasoning。
- [ ] 画布和生图工作台调用同一官方 Codex 图片路径，参考图片与用户参数传递完整。
- [ ] 保存并导入真实图片；损坏图片、越界路径、symlink或仅文本结果不能变成成功。
- [ ] 刷新、取消、连接中断和服务重启不重投生成；保留任务结果恢复入口。
- [ ] 离线协议测试、前端类型检查、构建与非费用UI回归通过。
- [ ] 真实账号生图另待用户允许使用账号额度后验收，不把离线通过写成实际生成成功。
