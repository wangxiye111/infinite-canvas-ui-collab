# 本机跨浏览器历史

按已确认的本地独立项目需求，画布、素材及图片／视频工作台历史保存至本机连接服务的数据目录。浏览器继续保留现有数据；首次读取时把本浏览器尚未保存到服务的数据复制过去。凭据和渠道设置不在此范围内。

使用现有 localforage 序列化器保存 Blob 和 JSON；磁盘记录原子替换。每条记录具有修订号，过期页面写入时拒绝覆盖并提示刷新。删除保留墓碑，防止旧浏览器再次导入。媒体清理只清理浏览器缓存，避免其他浏览器引用的文件被误删。

同名记录已在服务中时，以服务记录为准，原浏览器副本仍保留，不自动合并。同一页面加载后遇到修订冲突会显示错误并拒绝覆盖。同一服务地址在不同浏览器重新打开可读取最新历史；不实现实时多人协作或跨电脑同步。

待确认旧任务在编辑器直接提供核查后新一轮入口，原记录留在历史，不自动提交。
