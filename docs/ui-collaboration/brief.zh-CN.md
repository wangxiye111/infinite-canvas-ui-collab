# AI 创作画布 · 项目与设计想法

[English](brief.en.md) · [本地运行说明](README.md)

Alok，谢谢你愿意看看这个项目。我把产品想法和目前遇到的设计问题整理在这里，希望能听听你的建议，也方便你判断有没有感兴趣的组件可以尝试。

## 我在做什么

我在 [infinite-canvas](https://github.com/basketikun/infinite-canvas) 的基础上，做一个自己和几个朋友使用的本地 AI 创作画布，主要用于生图和生视频。

我们会用到 GPT、Gemini、可灵、即梦和 RunningHub。希望把参考图、提示词、生成和结果整理放在同一张画布里，减少在不同网站之间反复上传、复制和下载的操作。

一个常见的创作过程是：

**放入参考图 → 写提示词 → 生成几张候选 → 选一张继续修改或生成视频 → 在画布中查看和整理结果。**

画布旁边还有一个聊天助手，用来讨论想法、分析选中的图片和优化提示词。

## 我喜欢的方向

[Lovart 的画布](https://www.lovart.ai/canvas) 一直是我想接近的整体体验。它是这个项目最主要的设计参考；[LibTV](https://www.liblib.tv/canvas) 则是我参考图片、视频创作流程的另一个产品。

我也很喜欢 Cue 里的这些组件：

- **Image Generation Job Card**：生成任务的状态反馈。
- **AI Chat Card With Reply**：聊天和引用回复的交互。
- **Made For Cue Hero Preloader**：首页的开场体验；在我的产品里，入口更适合是「打开画布」按钮。

我想保留这些交互带来的感觉，同时让它们融入画布自身的风格。

## 目前最困扰我的地方

单个组件看起来很好，但放在一起后，整个页面的视觉不统一。字体、间距、按钮、面板和动效缺少共同的规则，画布、助手和设置页也不太像同一个产品。

最想先理清的是创作时的主界面：作品应该是视觉中心，参考图、提示词、模型选择和生成按钮要容易找到；打开助手或参数面板后，画布仍然清楚、舒适。

另外两个具体问题是：生成中或失败时，用户不容易判断发生了什么；连接设置页的信息较多，操作与说明的层级不够清楚。

## 可以一起讨论的小切入点

下面几个方向都对我有帮助，可以按你的兴趣和时间选一个：

- 看一眼完整画布，给一些布局、字体、间距和风格统一方面的建议。
- 尝试一个适合画布的图片／视频创作面板，把参考图、提示词、模型和生成放在一起。
- 围绕生成状态卡或聊天助手做一个组件示例，看看怎样与画布搭配。

如果其中一个方向合适，我们再一起确定具体范围。一个布局草图、交互建议或组件示例，都可以帮助我继续完善项目；代码整合和其他页面我会继续跟进。

## 供参考的功能细节

- 图片：文字生成、多张参考图修改、多个候选和历史版本。
- 视频：文字生成、图片生成、首尾帧；在节点中播放和切换结果。
- 节点连接：把图片作为下一个节点的参考，由用户点击生成。
- 结果：候选和历史收在原节点，选中的结果作为当前输出，也可以单独拖出。
- 助手：聊天、分析选图、优化提示词，用户确认后应用到节点。

现阶段最关注图片、视频和助手的创作体验。更详细的功能记录保留在项目文档中，有需要时再展开讨论。
