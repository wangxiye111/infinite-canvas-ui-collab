# 平台节点开发版测试

## 打开当前开发版

在项目根目录运行 `node start-dev.mjs`，打开 http://127.0.0.1:5173/canvas 。此入口直接运行源码开发预览，不需要先构建；需要现有 `web`、`canvas-connectors` 依赖已安装。

原 `3000` 页面仍使用此前的打包文件，刷新它不会更新到这批代码。开发版的浏览器项目、素材和配置与 `3000` 分开；平台服务数据位于用户目录 `.infinite-canvas/connectors-development`。看到空画布库不表示原项目丢失。如需复制项目，请从原页面导出画布包，再在开发版导入。

## 不消耗额度的界面测试

1. 新建画布，分别添加「图片」「视频」节点。
2. 点击节点编辑器底部模型名称。个人模型、可灵、即梦和 RunningHub 工作流在同一菜单中；未配置平台显示配置入口。
3. 输入提示词，在同一菜单切换模型或平台预设；编辑器和提示词应保留。未确认原任务时禁止切换。
4. 点击模型菜单的配置入口，或画布右上角「画布设置与更多」中的「平台连接」。核对可灵、即梦的安装检测，以及 RunningHub 的 Key 配置说明；浏览器网页登录不等于 CLI 已授权。
5. 可灵与即梦连接成功后，模型自动进入节点菜单；点击「参数」调整清晰度、比例、数量或时长，无需手写预设。RunningHub 仍需在「任务预设」配置真实工作流标识、提示词、参考角色、固定参数和输出类型。保存预设不会生成内容。
6. 回到节点选择预设。图片节点只出现图片输出预设，视频节点只出现视频输出预设；特殊多类型工作流继续使用独立任务节点。

## 接通账号后的真实流程

点击「生成」才会提交到对应平台，并可能消耗其额度。开始前应先完成可灵／即梦官方 CLI 安装授权，或在开发版配置 RunningHub Key。当前不自动改用付费 API。

1. 文生图／文生视频：选择对应预设，输入提示词并生成。文生预设有参考素材时应拒绝提交，要求换图生预设或断开素材。
2. 参考图生图：将图片连接到目标图片节点，或勾选参数中的「用当前图片作为参考」；只使用当前输出，不混入历史候选。
3. 图生视频：将选中的图片连接视频节点。可灵按所选模型能力指定首帧及可选尾帧；即梦「图生视频」接收单张图片，「首尾帧生视频」需两张图片，并在参数中分别指定首帧和尾帧。Seedance 2.5 参考帧模式不展示不支持的比例参数。
4. RunningHub：为每个参考素材分配已配置的角色。重复／缺失角色应在上传前阻止；没有提示词映射时留空使用工作流内置内容，填写提示词应得到明确提示。
5. 结果应进入原节点候选；已有选中输出保持不变，点击候选才切换。首次空节点可选首个成功结果。视频在节点内播放。
6. 已完成任务再次点击生成，旧批次应进入「候选与历史」；选择历史结果或「另存为节点」不应产生平台生成请求。
7. 改变上游选图后，原批次仍使用提交时的参考快照；已有结果保留，下一次手动生成才使用新素材。

当前参数来自节点选择时保存的预设快照。修改预设目录后，未提交的节点可点击参数中的「使用已更新的预设」；已提交任务不随目录改变。

## 恢复与异常测试

- 提交后刷新页面，重新打开该节点面板，应读取／查询原任务，不能自动再次提交。
- 查询失败后点击「查询原任务」；平台已完成的结果应恢复下载。无法确认原任务时，可核实平台记录后，经确认开始新一轮；它不会取消远端原任务。
- 本地存储写入失败应阻止新的付费提交。远端成功但浏览器素材保存失败，应显示保存失败并保留已经保存的候选。
- 切换画布或删除节点后，迟到结果不得写入另一个节点。平台任务记录仍可在平台设置中查询。

任务查询目前随打开的节点面板进行；离开面板不取消平台任务，重新打开后继续恢复。

## 离线候选样例

运行 `node web/tests/platform-preview-fixture.mjs` 会在系统临时目录生成 `canvas-platform-preview.zip`。通过画布库的「导入画布」手动导入，可测试历史候选选择、另存节点，以及不存在的任务查询失败后能否进入确认流程。样例图片为合成色块，任务和模型标识明确为测试值，不是真实生成记录；不要用此预设发起生成。

已在独立 IAB 页面导入合成样例，验证候选选择、原任务查询失败后的核查确认、切换个人模型后提示词与历史保留；未提交样例任务。
